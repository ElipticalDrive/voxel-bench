# u8 ids

## What it is

`bricks` with an 8-bit id per voxel: half the footprint (32 KiB per chunk), at most 256 block
types.

## How it works

The brick mask as in `bricks`, the ids as bytes.

## In this project

`components/src/storage/u8/cpu.rs`. CPU only.

## Measured

Cycles per pixel are unchanged against `bricks`: shrinking the world data does not help a CPU
walk that is not memory bound (see [brick-layouts](brick-layouts.md)).
